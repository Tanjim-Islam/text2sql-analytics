# Text2SQL Analytics System (Makebell)

This repository contains the implementation for the Makebell Backend Engineer Assessment: a production-ready Text2SQL analytics system over the Northwind dataset using PostgreSQL and Google Gemini. See `Makebell_Home_Task.pdf` and `PLAN.md` for details.

Getting started

- Create and activate the Python virtual environment (`.venv`).
- The primary project will be created under `text2sql-analytics/` with the exact structure specified in the PDF.
- After scaffolding, see `text2sql-analytics/README.md` for complete setup and usage instructions.
